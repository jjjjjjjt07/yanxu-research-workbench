## 技术实现与计划的调整

前端仍采用 React + TypeScript。为了让四个模块能在同一个私有演示站点运行，首版服务端采用 TypeScript / Cloudflare Workers，结构化状态存入 D1，文件存入 R2，替代最初计划中的 FastAPI / PostgreSQL。PDF 在浏览器使用 PDF.js 解析，再将文档、文本和坐标保存到服务端，避免在受限服务端内存中运行大型 PDF 解析器。

项目记录采用带 revision 的有界状态快照，文献全文单独保存到 R2。每次保存必须匹配服务器版本；冲突时拒绝覆盖。未来高频协作可将单元格和修订历史进一步拆为独立表。

## 本地启动

需要 Node.js 22.13 或更高版本，以及 npm。Windows PowerShell 如果阻止 npm.ps1，使用 `npm.cmd` 和 `npx.cmd`。

```powershell
cd yanxu-research-workbench
npm.cmd install
npm.cmd run db:migrate
npm.cmd run local
```

首次运行需要先复制 `.env.example` 为 `.env` 并填入模型配置（见下方「配置模型」）。`npm run db:migrate` 只初始化本机的 D1 数据库，不访问网络。macOS / Linux 上把 `npm.cmd` 换成 `npm` 即可，项目脚本本身跨平台。

直接免登录使用请双击 `启动研序.cmd`，或执行 `npm.cmd run local` 并打开 `http://127.0.0.1:3000`。双击入口会在后台启动服务，再打开默认浏览器，重复启动会复用已运行的服务。关闭浏览器不停止后台任务，关机后需要重新启动。数据保存在本机。

普通 `npm.cmd run dev` 保留原有本地测试登录，默认地址 `http://localhost:3000`。免登录只对显式启用的本地运行模式生效，仅监听回环地址；正式云端仍使用平台身份。不要将本机模式当作公网匿名演示部署。

`predev` / `prebuild` 自动复制 PDF 中文字符映射、字体和 WASM 资源。它们来自锁定的 pdfjs-dist 依赖，原始依赖不需要提交。

本地数据库与文件位于 `.wrangler/state`，刷新页面或重启仍保留。请勿把该目录提交到代码仓库。云端与本地数据独立，上传云端的资料不会自动出现在本地。

## 配置模型

新环境将 `.env.example` 复制为 `.env` 并填写服务端配置；已有 `.env` 时保留原文件。`npm.cmd run dev` 会同时启动网页与后台执行器，两者读取相同配置。单独使用 `.dev.vars` 时，需要额外为 Node 后台执行器提供相同环境变量。

```dotenv
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-flash
AI_API_KEY=你的密钥
AI_DAILY_CALL_LIMIT=100
JOB_RUNNER_SECRET=替换为至少32字符的随机服务端密钥
```

`AI_BASE_URL` 必须是 HTTPS，并且不带末尾的 `/chat/completions`。程序在调用时添加该路径。配置后重启开发服务，打开「模型与用量」刷新状态。状态“已配置”只表示配置项齐全，实际连通性由调用结果验证。

默认接入 DeepSeek 官方接口；仍允许使用已验证的兼容接口覆盖服务端配置。后台执行器密钥不能发送给浏览器。修改配置后需要重启整个工作台服务。关闭网页不会停止任务；关闭服务或电脑会暂停执行，重启后从持久化状态恢复。

云端密钥通过 Sites 的运行时密钥配置设置，之后部署新版本生效。不要修改 `.openai/hosting.json` 来保存密钥，也不要把 `.env`、`.dev.vars` 放进源码或提交到仓库。

每日次数限制包含失败请求。它是调用次数上限，不是准确的金额预算；实际费用还取决于模型价格、上下文长度与失败计费规则。输入 / 输出 Token 在调用返回用量后记录。

模型参数当前使用 `temperature: 0.1` 与 `max_tokens: 6500`。DeepSeek 官方接口额外启用 JSON 输出、关闭思考模式；其他兼容接口保持原有参数。当前接入 `deepseek-flash`（V4.1 Flash），实际输入、输出和模型配置保存为运行记录。阅读页支持单页 OCR 候选核对与接纳；旧 Flash/Pro 结果保留为历史测试，当前验收见上述实施记录。

## 第一版的明确边界

1. 支持文字 PDF / TXT；扫描件需先 OCR。每课题最多 20 篇、15 个字段，每篇最多 15 MB、80 页和 80,000 解析字符。复杂双栏、跨页表格、公式与图中数据需要人工核对。
2. 引用检查验证来源编号、摘录存在性和页面位置，不证明一个结论在语义上一定成立。人工确认与来源有效性分别记录。
3. 当前问答围绕选中的一篇论文或原文片段，尚未实现大规模跨文献向量检索。
4. PDF 原文位置基于客户端解析结果；尚未提供独立服务端二次解析核验。原文件保留供人工检查。
5. 提取任务记录持久化，但执行由用户请求驱动。关闭页面后，未完成任务可继续，不承诺无人值守后台队列持续运行。
6. 规则由用户确认，最新版是该字段的完整提取规则；新增规则后需要点击重新提取。自动学习用户纠错偏好仍属后续工作。
7. 每实验最多 10 个版本，每版本最多 2000 行，最多 5 个实验。数据关系由用户显式绑定；不自动理解全部论文句子，也不执行统计显著性判断。
8. 改稿首版使用站内段落，不直接编辑完整 Word / LaTeX 稿件；行级差异不是精确的语义差异。保存新版本会把旧的意见核对记录归档。
9. 当前支持 CSV 与 JSON / Markdown 导出；XLSX 和 Zotero 同步可在下一轮加入。
10. 面向个人私有使用；多人实时协作、附件全文备份导入、独立后台队列和自动化保留集评测尚未实现。
