# 公网发布与复测记录

修复对象是上一轮真实论文验证发现的一条摘录空白差异及两篇论文构图不完整。服务器现在将空白归一化后可唯一定位的引文恢复为原文字符；无法唯一定位时引用完整的原文块，且主张仍须经过独立语义支持检查。双栏分割采用更细的分割点和较窄的页间距，构图模型使用带编号的原文片段，服务器保存字面原文。实体提及跨相邻片段时只在同页紧邻且唯一命中的片段中修复；仍无依据则隔离，不会伪造引用。

复测材料来自 PMLR 的 Gilmer 等人《Neural Message Passing for Quantum Chemistry》与 Beaini 等人《Directional Graph Networks》，以及 arXiv 的 Veličković 等人《Graph Attention Networks》。本地校验见 `outputs/revalidation-public/report.json`：15/15项机器流程检查通过；最新一轮三个构图任务均为 `succeeded`，摘录及页码定位通过；三道问答分别保留25、12、3条可定位来源，均已持久化；桥接和三篇全文的两字段提取完成。`report-round1.json` 和 `report-round2.json` 保留了修复过程中确实失败的批次。累计图谱105实体、140关系、149条证据包括多轮候选，不能当成单轮质量或人工确认数。120项规则测试、类型检查和生产构建通过。

公网运行时使用 `PUBLIC_ACCESS=1` 与独立 `GUEST_SESSION_SECRET`。每个浏览器获得30天有效的签名、HttpOnly访客Cookie；所有项目、文件、任务均按访客ID隔离，原有登录用户的数据不会作为匿名数据返回。清理Cookie或换浏览器会失去原访客空间的访问权限。全站AI调用每日上限另由 `AI_PUBLIC_DAILY_LIMIT` 控制。云端任务由页面在用户操作和轮询时驱动；运行时保持页面打开，刷新后可恢复排队或超时任务。本地公网模式预演通过8项验证：匿名拒绝、访客隔离、来源读取、Cookie篡改和跨站来源拦截、云端任务权限。

学术验收仍需固定的20篇跨领域全文、独立研究者标注与保留集、真实实验复现数据和效率对照。机器检查通过只说明这些样例的指定软件流程和定位规则可运行，不证明科研结论正确。
