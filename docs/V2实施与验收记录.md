## 2026-09-17 追加：两组比较、配对与多重比较校正

实验页新增两组比较，限定当前实验版本、同一数据集和指标下两个不同方法的完整运行记录。独立设计使用 Welch 两样本 t 检验，允许两组样本量和方差不同；配对设计按 runId 匹配而非行序，要求两组编号完整一一对应，缺失时拒绝，不自动丢弃记录。每组至少两条有效编号运行。用户须填写单位、观测单位、相同条件、独立性与近似正态依据；配对设计另需确认配对依据，独立性和正态前提针对配对差值。设计默认未选择，确认默认未勾选，变更方法或设计后需重新确认。

固定检验双侧均值差为0，报告 A−B 原单位均值差、标准误、自由度、t、原始及校正 p 值和差值区间。原单位差是本轮效应量，尚无标准化效应量或功效分析。单次比较使用0.05阈值和95%区间；Bonferroni 按用户声明的完整比较总数 m（2—100）计算 min(1,m×p)、0.05/m 阈值及 t(1−0.05/(2m),df) 区间。计划文本及确认必填，须覆盖本软件外的相关比较；软件不能验证是否完整或事先确定，因此不宣称已自动完成预注册或多重比较族管理。未拒绝零差异不等于两方法等效。

公式参考 [NIST 两样本 t 检验](https://www.itl.nist.gov/div898/handbook/eda/section3/eda353.htm)、[NIST 配对检验](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)及 [NIST Bonferroni 区间](https://itl.nist.gov/div898/handbook/prc/section4/prc473.htm)。继续使用 jStat 1.9.6；双侧尾概率用不完全 beta 形式直接计算，避免 1−CDF 的大 t 消减误差。标准误为零、非正规浮点范围、区间溢出或塌缩、尾概率下溢时拒绝保存，不输出伪造的 p=0。用户确认前提不等于软件已检验其成立，不自动切换统计方法。

服务端从保存的原始运行重新计算，不信任客户端结果或预存统计摘要。每条记录保存实验/数据版本、原始行索引及运行编号、全版本输入哈希、配对明细、公式/算法标识、完整前提/比较计划、操作者/时间/说明。保存比较不改数据版本或原件，每实验最多50条；后续数据或复现资料版本变化后，旧结果仍保留并显示旧版本，不自动成为新结果。支持下载记录及对应输入版本，完整课题记录包包含比较历史。

验证：104项规则测试、29次无模型接口请求、类型检查及生产构建通过，本地页面 HTTP 返回200。数值验证包括不等样本量 Welch 对照独立 Python 标准库数值积分、已知自由度的解析尾概率、按编号而非行序配对、反向比较、Bonferroni 后区间/判定、极端尾概率及退化输入拒绝。接口覆盖未确认前提、非法比较计划、未匹配配对、非法目标/身份、旧实验版本及课题并发冲突、客户端伪造结果、原数据不变、旧结果保留、重新计算和完整导出。脚本微调后的语法检查通过，未为重复验证而再次消耗实验版本。

现有稿件描述数值核对遇到多次运行时返回无法判断并解释尚未指定运行或统计量，不自动选择第一行或用均值替代。观察仍捕获用户选择的原始行；统计摘要尚未作为独立计算证据直接绑定问答/稿件。这避免把新的均值汇总悄悄改变成旧描述的依据。规范CSV导出显式选择runId列，即使首行属于未编号单值组，后续重复运行编号也不会因自动推断表头而丢失。

「均值置信区间」每次选择一个方法/数据集/指标分组的全部运行，固定计算双侧95% Student t均值区间。保存前须填写指标单位、独立观测单位、相同条件范围、独立性依据、近似正态分布依据和本次说明，并明确确认两个前提；默认均不确认，服务端再次验证。用户填写前提不等于软件验证其成立。至少需要2条有编号且有变动的运行；单次、零变动、基础统计失败、区间溢出、标准误进入非正规浮点范围或精度不足导致端点塌缩时拒绝保存。前提不适用时保留描述统计，不自动切换其他推断方法。

公式为均值±t(0.975,n−1)×样本标准差/√n，参考 [NIST均值置信区间](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)；标准差采用n−1分母，参考 [NIST尺度统计量](https://www.itl.nist.gov/div898/handbook/eda/section3/eda356.htm)。t分位数使用固定依赖 [jStat 1.9.6](https://github.com/jstat/jstat)，已更新依赖锁文件。软件只做这一单组均值区间，不输出p值、组间显著性、配对比较或同时覆盖保证；误差条明确标为均值95%区间，不能当作每次运行值的95%范围。

## 2026-09-14 追加：实验观察用于问答与稿件

阅读助手允许明确选择最多5条当前实验观察，默认不选择；切换选择或所选观察版本变化会开始新对话。只将所选观察的文字、条件、人工判断、实验版本和所选数据行作为用户实验记录传给模型，不发送观察历史或把其假设引用当作论文事实。待复查、撤回或数据版本不匹配的观察不能作为新问答输入；服务端另核验实验快照哈希、数据行与关联图谱来源。现有阅读问答仍需选择文献，不新增纯实验聊天入口。

模型逐项回答新增与论文来源分开的实验观察索引，拒绝越界/重复索引成为有效依据；服务端将使用实验观察的事实类型转换为综合推断，并限制支持性。实测曾发现模型将“未知”主张标为支持，现补充规则：未知主张保持未知，未独立复算的计算、综合推断和用户实验观察不能仅靠模型评分标为充分支持。这个保护不替代研究者核对所有语义或模型遗漏标注的观察引用。

回答保留当时所选观察的完整快照和版本；历史列表按每条回答当时选择的观察计算上下文变化，并标出失效观察。不选择观察时沿用旧上下文结构，避免所有旧问答无故失效；修改无关观察不影响未选择它的回答。旧回答与快照不改写，观察恢复原文字仍产生新版本，不能把旧回答重新标为当前。
